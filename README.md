# Moba Universe — Backend

REST API для [mobauniverse.com](https://mobauniverse.com). Отдельный сервис после выделения из монолита; клиент — [moba-universe-frontend](https://github.com/Grootoss/moba-universe-frontend).

## О проекте

Backend обслуживает публичный сайт и админку: гайды (evergreen-статьи), регистрацию и авторизацию, личные кабинеты игроков с модерацией профилей, публичный каталог пользователей и SEO-эндпоинты.

Контент статей хранится в PostgreSQL и управляется через admin API. Sitemap и robots.txt генерируются динамически из БД при каждом запросе — новые опубликованные статьи и профили попадают в sitemap без ручного обновления файлов.

## Технологии

- **FastAPI** — HTTP API, валидация через Pydantic
- **SQLAlchemy 2** — ORM, модели и связи
- **PostgreSQL** — основное хранилище
- **Alembic** — миграции схемы
- **JWT** — access/refresh-токены, роли `user` / `moderator` / `admin`
- **bcrypt** — хэширование паролей

## Архитектура и подходы

- **Роутеры по доменам:** `auth`, `profiles`, `articles` (`/api/evergreen/articles`), `admin`, `seo`
- **Двуязычный контент статей** — отдельная таблица переводов (`ru` / `en`) на одну запись
- **Модерация профилей** — nickname и bio проходят проверку; игры и ранги сохраняются сразу из справочника MOBA-игр
- **Публичная выдача** — только `published` статьи и одобренные публичные профили; staff исключается из списка пользователей
- **Конфигурация** — `pydantic-settings`, переменные окружения (БД, JWT, CORS, `SITE_URL`, admin seed)
- **Seed** — начальные категории гайдов, демо-профиль Rootoss и admin; статьи добавляются через админку

## Основные возможности API

| Область | Назначение |
|---------|------------|
| Auth | регистрация, вход, refresh, `/me` |
| Evergreen articles | список и карточка гайда с датами `created_at` / `updated_at` |
| Profiles | свой кабинет, отправка на модерацию, публичный `/user/{id}` |
| Users | каталог опубликованных профилей |
| Admin | CRUD статей, модерация профилей, разблокировка редактирования |
| SEO | `/sitemap.xml`, `/robots.txt` |

## Деплой

Сервис рассчитан на запуск в Docker; PostgreSQL — на хосте или отдельном инстансе. Образ при старте применяет миграции Alembic и поднимает Uvicorn.
